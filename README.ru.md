## О проекте

Tech Card Manager (TCM) в режиме только для чтения сканирует выбранные пользователем NFO фильмов и сериалов, строит собственный производный индекс и через Emby Web Card показывает камеры, объективы, форматы съёмки, звук, соотношение сторон и производственные процессы.

TCM не получает данные IMDb, не записывает NFO и не создаёт теги. Для создания или обслуживания этих данных используйте отдельное приложение [IMDb Tech Manager (ITM)](https://github.com/Eric-Hou1997/IMDb-Tech-Manager).

- Release содержит SHA-256, инструкции, список изменений и языковые пакеты

## Основные возможности

- Раздельные каталоги, индексы, поиск, фильтры и обновление фильмов и сериалов
- NFO Inspector только для чтения и диагностика XML с полными путями
- Установка, обновление, удаление и проверка состояния Emby Web Card
- Один экземпляр Windows, системный трей, запуск при входе и тихий режим
- Адаптивная компоновка заголовка, панели состояния, инструментов NFO и двух панелей
- Проверка обновлений с отдельными ошибками прокси/сети, лимитов GitHub, ресурсов и загрузки

## Языки

Упрощённый китайский, традиционный китайский и английский (США) встроены в Portable EXE. Французский, русский, японский, испанский и тайский распространяются отдельными пакетами в Release `v4.1.0` и загружаются только после скачивания и проверки.

Язык нового журнала фиксируется при запуске задачи. Старые журналы, NFO, индекс, резервные копии и пользовательские данные не переписываются. Неустановленный или неподдерживаемый язык Emby использует упрощённый китайский. Ключи `Camera`, `Sound mix` и структура JSON остаются неизменными — переводится только отображение.

## Границы безопасности

- NFO всегда остаются для TCM источником только для чтения; индексация не меняет байты и время файла.
- Web Card изменяет только проверенные Web-файлы Emby с внешней резервной копией, блокировкой, CAS, журналом и атомарной заменой.
- Миграция старых компонентов и административные операции показывают план и требуют явного подтверждения.
- Если путь, владение или резервная копия не проверены, операция безопасно останавливается.

## Установка и обновление

Полностью распакуйте ZIP, запустите `Tech-Card-Manager.exe`, отдельно задайте каталоги фильмов и сериалов, создайте индекс и настройте Web Card по подсказкам. Во время использования карточки TCM должен работать; окно можно свернуть в трей.

Portable-версия не заменяет работающий EXE автоматически. Полностью выйдите через трей, распакуйте новую версию и замените программу, сохранив каталоги `data`, `logs`, `backup`, `runtime` и `updates`.

## Дорожная карта

Готово: Windows x64 Portable, индекс NFO только для чтения, отдельные пространства фильмов/сериалов, безопасная Web Card, жизненный цикл трея, многоязычный реестр и пять пакетов, обновление через прокси и адаптивная компоновка по содержимому.

В работе: больше реальных тестов Windows/Emby/PowerShell 5.1/UAC, совместимость с DOM Emby и типами медиа, восстановление старых компонентов, Portable-обновление и другие платформы.
