v4.0.4 / 更新说明 / Changelog
=============================

中文
----

- 完成 Manager Web UI 简体中文与 English (United States) 即时切换，包括主界面、目录、筛选、设置、维护、任务、更新、Toast、空状态、placeholder、title、aria-label、日期与 `<html lang>`。
- 语言切换只更新显示文案，不重载页面，不改变电影/电视剧空间状态、选择、筛选、滚动、弹窗和未保存输入。
- 建立可扩展语言注册表。Technical Specs 协议字段键、NFO 数据、Ownership、索引结构和 JSON 协议保持稳定，只翻译显示名称。
- Web Card 对中文 Emby 使用中文、对英文变体使用英文；日语、西班牙语等暂未翻译语言回退中文。卡片 aria-label 与无数据提示同步本地化。
- Go API 状态、错误、更新信息、原生托盘菜单、目录选择说明、启动/退出错误与退出确认支持双语。
- 任务启动时固定日志语言，避免运行中切换形成混合日志；旧日志不改写。
- 响应式布局改为由实际内容宽度和 Flex/Grid 换行决定，按钮组保持成组，长语言不会依赖中英文专用断点。
- 老用户不需要缓存迁移：旧设置缺少语言时默认中文，现有 NFO、`manager-items-cache.json`、`manager-state.json`、`manager-index-summary.json`、`manager-catalog.json`、Web Card v7 数据、备份与日志均不做破坏性转换。
- 增加英文隐私政策、使用条款以及中英双语发布文档。

English
-------

- Added instant Simplified Chinese and English (United States) switching across the Manager Web UI, including the dashboard, folders, filters, settings, maintenance, tasks, updater, toasts, empty states, placeholder/title/aria-label text, dates, and `<html lang>`.
- Language switching updates display copy only. It does not reload the page or reset Movie/TV state, selection, filters, scroll positions, dialogs, or unsaved input.
- Added extensible locale registries. Technical Specs protocol keys, NFO data, ownership, index structures, and JSON protocols remain stable; only display labels are translated.
- The Web Card uses Chinese for Chinese Emby locales and English for English variants. Untranslated locales such as Japanese and Spanish fall back to Chinese. Card aria labels and empty states are localized too.
- Added bilingual Go API status and errors, update information, native tray actions, folder-picker description, startup/shutdown errors, and exit confirmation.
- Each task captures its log language when it starts, preventing mixed-language logs after a live switch. Historical logs are not rewritten.
- Responsive layout now follows measured content through Flex/Grid wrapping. Command groups stay together, and long translations do not rely on Chinese- or English-specific breakpoints.
- Existing users need no cache migration. Old settings without a language default to Chinese; existing NFO files, `manager-items-cache.json`, `manager-state.json`, `manager-index-summary.json`, `manager-catalog.json`, Web Card v7 data, backups, and logs are not destructively converted.
- Added English privacy and terms documents plus bilingual release documentation.

Validation status / 验证状态
----------------------------

- Source contracts, runtime localization checks, JavaScript syntax, Windows x64 Go test compilation, Go vet, and Windows x64 GUI cross-build are part of the source gate.
- Real Windows, PowerShell 5.1, UAC, tray, Edge, and live Emby DOM behavior remain target-machine acceptance items.
- No release package, tag, push, or GitHub Release is implied by this source changelog.
