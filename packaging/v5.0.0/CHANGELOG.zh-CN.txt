v5.0.0

本版迁移至 Rust + Tauri 2 + TypeScript + Vue 3/Vite，以 v4.1.0 的功能、界面和操作为基线。TCM 仍是只读 NFO 与 Emby 技术规格卡片管理器，没有 AI、NFO 写入或自动安装更新。

发行目标：macOS ARM64 DMG、Windows x64/ARM64 NSIS、Linux x64/ARM64 AppImage/DEB/RPM，共五目标九包，没有 macOS Intel。包名与原手动更新流程按实际安装渠道绑定。

保留旧 Windows 源码、数据迁移、确认清单、权限维护、事务备份与失败恢复。补齐只读 NFO 编码兼容、首次索引失败状态、重试及服务停止清理；媒体 NFO 字节和修改时间保持只读。

内置简体中文、繁體中文和英语，五种外部语言以 r2 语言包提供，补齐必要的平台与失败提示。已验证的 r1 安装文件可离线继续使用；新版下载失败不删除旧语言或用户数据。

安装与升级：下载匹配的包，核对 TCM-v5.0.0-SHA256SUMS.txt，从菜单栏或托盘完全退出后安装/替换。保留系统用户数据、Emby 维护备份和旧 Portable 的全部原文件。DEB/RPM 通过系统包管理器安装或升级。

分发与验收边界：macOS 使用临时签名，未做 Apple 公证；Windows 未做发行证书签名。真实 Emby、完整原生界面/操作与 Windows/Linux 运行验收尚未完成。源码回归、架构及包检查不代表这些真实验收通过，不能把目标列表视为经实机认证的支持声明。

从 v4.1.0 升级时，旧程序只匹配旧 Portable ZIP，不能直接识别 v5 的新安装渠道；请直接前往官方 Releases 下载匹配的 v5 包。不要把 NSIS 安装器当成旧 Portable 的主程序替换，保留原目录并按新版内的迁移清单确认数据。
