## 🎬 เกี่ยวกับโครงการ

**Tech Card Manager (TCM)** นำ **Technical Specifications** ที่มีอยู่แล้วในไฟล์ NFO ของสื่อเข้าสู่ประสบการณ์การเรียกดูจริงของ Emby

คลังสื่อส่วนใหญ่แสดงข้อมูลต่อไปนี้ได้ดีอยู่แล้ว:

* ชื่อเรื่อง
* นักแสดง
* ปี
* ความละเอียด
* ตัวแปลงสัญญาณวิดีโอ
* ตัวแปลงสัญญาณเสียง
* ข้อมูลสตรีม เช่น HDR / Dolby Vision

แต่ข้อมูลระดับการผลิตต่อไปนี้มักไม่ได้แสดงอย่างครบถ้วนเป็นโครงสร้าง:

* ใช้กล้องชนิดใด
* ใช้เลนส์ชนิดใด
* ใช้รูปแบบการถ่ายด้วยฟิล์มหรือดิจิทัลใด
* เกี่ยวข้องกับกระบวนการถ่ายภาพยนตร์ใด
* ใช้รูปแบบเสียงใด
* ใช้อัตราส่วนภาพใด
* มาสเตอร์และนำเสนอผลงานอย่างไร

TCM สแกนไฟล์ NFO ของภาพยนตร์และรายการทีวีในโฟลเดอร์ที่ผู้ใช้กำหนดใน **โหมดอ่านอย่างเดียว** สร้างดัชนีอนุพันธ์ของตนเอง และแสดงข้อมูลจำเพาะเหล่านั้นบนหน้ารายละเอียดสื่อผ่าน Emby Web Card

เป้าหมายหลักของ TCM คือ:

* นำ Technical Specifications ที่มีอยู่เข้าสู่ประสบการณ์เรียกดูคลังสื่อ
* รักษาไฟล์ NFO ต้นฉบับให้เป็นแบบอ่านอย่างเดียวอย่างเคร่งครัด
* ไม่เข้าถือสิทธิ์ในกระบวนการเมทาดาทาเดิมของผู้ใช้
* จัดการและรีเฟรชคลังภาพยนตร์กับรายการทีวีเป็นพื้นที่แยกกัน
* บำรุงรักษา Emby Technical Specifications Web Card อย่างปลอดภัย
* มี GUI สำหรับ Windows การผสานรวมถาดระบบ และบริการภายในเครื่องที่เหมาะกับการใช้งานต่อเนื่อง
* ทำให้สถานะ ข้อผิดพลาด และงานบำรุงรักษาที่สำคัญสังเกตและตรวจสอบได้
* มีภาษาจีนตัวย่อ จีนตัวเต็ม และอังกฤษ (สหรัฐอเมริกา) ในตัว พร้อมชุดภาษาที่ผูกกับรุ่นสำหรับฝรั่งเศส รัสเซีย ญี่ปุ่น สเปน และไทย

## ✨ ความสามารถหลัก

### 📚 การจัดทำดัชนี NFO แบบอ่านอย่างเดียว

TCM อ่านโฟลเดอร์คลังภาพยนตร์และรายการทีวีที่ผู้ใช้กำหนด และดึง Technical Specifications พร้อมข้อมูลแบบอ่านอย่างเดียวอื่นที่ใช้ในการแสดงและระบุตัวตนออกจากไฟล์ NFO

ไฟล์ NFO ของสื่อเป็น **แหล่งข้อมูลแบบอ่านอย่างเดียว** สำหรับ TCM

TCM จะไม่:

* แก้ไขไฟล์ NFO
* จัดระเบียบไฟล์ NFO ใหม่โดยอัตโนมัติ
* “ซ่อมแซม” ไฟล์ NFO โดยอัตโนมัติ
* เขียน Technical Specifications
* สร้างหรือลบแท็ก
* แก้ไขความเป็นเจ้าของแท็ก
* เปลี่ยนเนื้อหาต้นฉบับของไฟล์ NFO

TCM เก็บข้อมูลดัชนีไว้แยกต่างหาก

เมทาดาทาสื่อต้นฉบับยังอยู่ภายใต้การควบคุมของผู้ใช้และเครื่องมือเมทาดาทาที่ใช้อยู่ในกระบวนการเดิม

---

### 🖥️ Emby Technical Specifications Web Card

TCM แปลงข้อมูลจำเพาะทางเทคนิคที่จัดทำดัชนีแล้วเป็นข้อมูลที่เหมาะกับการนำเสนอในคลังสื่อ และผสานข้อมูลเข้ากับ Emby ผ่าน Web Card

ความสามารถปัจจุบัน ได้แก่:

* สร้างการ์ด Technical Specifications
* นำเสนอการ์ด Technical Specifications
* ให้บริการแอสเซ็ตของการ์ด
* ผสานรวมกับ Emby Web UI
* ติดตั้ง Web Card
* อัปเดต Web Card
* ลบ Web Card
* ตรวจจับสถานะ Web Card
* ตรวจจับความเข้ากันได้ของคอมโพเนนต์เก่า
* กระบวนการสำรองและกู้คืนที่จำเป็น

การบำรุงรักษา Web Card และข้อมูล NFO ของสื่อเป็นขอบเขตการทำงานสองส่วนที่แยกจากกันโดยสิ้นเชิง

TCM อาจดูแลไฟล์ผสานรวมเว็บของ Emby แต่ **จะไม่แก้ไขไฟล์ NFO ของสื่อเป็นส่วนหนึ่งของกระบวนการนั้น**

ตัวจัดการสามารถสลับระหว่างภาษาจีนตัวย่อ จีนตัวเต็ม และอังกฤษ (สหรัฐอเมริกา) ได้ทันทีโดยไม่ต้องโหลดใหม่หรือล้างสถานะ UI ปัจจุบัน ภาษาฝรั่งเศส รัสเซีย ญี่ปุ่น สเปน และไทยเป็นแอสเซ็ตแยกใน GitHub Release `v4.1.0` และจะโหลดหลังจากดาวน์โหลดและตรวจสอบแล้วเท่านั้น Emby Web Card มีรีจิสทรีภาษาของตนเอง ภาษา Emby ที่ยังไม่ได้ติดตั้งหรือไม่รองรับจะย้อนกลับไปใช้ภาษาจีนตัวย่อ คีย์ Technical Specs เช่น `Camera` และ `Sound mix` รวมถึงโครงสร้างข้อมูลพื้นฐานจะไม่เปลี่ยนตามภาษาที่แสดง

### 🎬 การจัดการภาพยนตร์และรายการทีวีแยกกัน

ภาพยนตร์และรายการทีวีเป็นพื้นที่สื่อแยกกันใน TCM

แต่ละพื้นที่มี:

* รากคลังแยกกัน
* ดัชนีแยกกัน
* การค้นหาแยกกัน
* ตัวกรองแยกกัน
* การเรียกดูแยกกัน
* ขอบเขตการรีเฟรชแยกกัน
* การแสดงสถานะแยกกัน

ตัวอย่าง:

```text
ภาพยนตร์
  ↓
รีเฟรชคลังปัจจุบัน
  ↓
สแกนเฉพาะไดเรกทอรีภาพยนตร์
```

การรีเฟรชภาพยนตร์จะไม่สแกนไดเรกทอรีรายการทีวีโดยอัตโนมัติ

เช่นเดียวกัน การรีเฟรชรายการทีวีจะไม่สแกนภาพยนตร์ซ้ำโดยอัตโนมัติ

### 🔎 การเรียกดูและตรวจสอบดัชนี

ตัวจัดการ TCM ไม่ได้มีไว้เพียงเริ่มบริการ แต่ยังใช้เรียกดูดัชนีสื่อที่สร้างไว้แล้วได้

ปัจจุบันสามารถแสดง:

* จำนวนชื่อเรื่องที่จัดทำดัชนี
* จำนวน NFO ทั้งหมด
* สถานะแคช / ดัชนี
* ข้อผิดพลาดการแยกวิเคราะห์ XML
* สถานะการเข้าถึงคลัง
* ไดเรกทอรีภาพยนตร์และรายการทีวี
* Technical Specifications
* แท็กทางเทคนิคและข้อมูลแบบอ่านอย่างเดียวอื่น
* พาธ NFO
* งานปัจจุบัน
* สถานะข้อผิดพลาด

เมื่อเกิดข้อผิดพลาด TCM จะเก็บข้อมูลวินิจฉัยที่มีประโยชน์ให้มากที่สุด เช่น ชื่อเรื่อง ประเภทสื่อ พาธ NFO และงานที่ได้รับผลกระทบ

## 🔄 กระบวนการทำงานหลัก

```text
NFO ของสื่อ
    ↓
สแกนและแยกวิเคราะห์แบบอ่านอย่างเดียว
    ↓
ดัชนีอนุพันธ์ TCM
    ↓
บริการภายในเครื่อง / แอสเซ็ตการ์ด
    ↓
Emby Web Card
    ↓
Technical Specifications ในคลังสื่อ
```

TCM ไม่เขียนผลลัพธ์ดัชนีกลับไปยังไฟล์ NFO ของสื่อ

TCM สามารถมองได้ว่าเป็นอะแดปเตอร์แบบอ่านอย่างเดียวที่อยู่ระหว่าง:

```text
ชั้นข้อมูล NFO
    ↓
   TCM
    ↓
ชั้นการนำเสนอ Emby
```

TCM อ่านข้อมูลจำเพาะที่มีอยู่ สร้างดัชนีการนำเสนอของตนเอง แล้วส่งข้อมูลนั้นไปยังหน้าจอคลังสื่อ

* สร้างดัชนีอนุพันธ์ Technical Specifications
* จัดการ Emby Web Card
* นำเสนอข้อมูลจำเพาะทางเทคนิคบนหน้าคลังสื่อ

ทั้งสองร่วมกันสร้างกระบวนการทำงานที่สมบูรณ์ได้:

```text
IMDb
  ↓
IMDb Tech Manager (ITM)
  ↓
NFO / Technical Specifications
  ↓
Tech Card Manager (TCM)
  ↓
การ์ด Emby Technical Specifications
```

TCM **ไม่จำเป็นต้องใช้ ITM**

สามารถใช้แหล่งข้อมูลอื่นได้ ตราบใดที่ NFO มีข้อมูล Technical Specifications ที่เข้ากันได้และ TCM รู้จัก

## 🚫 ขอบเขตผลิตภัณฑ์

Tech Card Manager กำหนดขอบเขตความรับผิดชอบไว้อย่างเข้มงวดโดยเจตนา

TCM จะ **ไม่**:

* ดึงข้อมูลจาก IMDb
* แก้ไขไฟล์ NFO ของสื่อ
* เขียน Technical Specifications
* สร้าง Technical Tags
* ลบแท็ก
* แก้ไขแท็กของผู้ใช้
* เรียกใช้ AI
* จัดการพรอมป์
* ติดตามการใช้โทเค็น AI
* ติดตามค่าใช้จ่าย API ของ AI
* เข้าถือสิทธิ์เมทาดาทา NFO
* ย้ายความเป็นเจ้าของ NFO

ความรับผิดชอบเหล่านี้เป็นของเครื่องมือจัดการข้อมูล เช่น IMDb Tech Manager

TCM มุ่งเน้นเรื่องเดียว:

**อ่านข้อมูลที่มีอยู่อย่างปลอดภัยและนำเสนออย่างเชื่อถือได้**

## 🔒 ความปลอดภัยของข้อมูลและการผสานรวมเว็บ

### ไฟล์ NFO ยังคงเป็นแบบอ่านอย่างเดียว

ระหว่าง:

* สแกน
* จัดทำดัชนี
* รีเฟรช
* ค้นหา
* นำเสนอ

TCM ต้องปล่อยให้เนื้อหา NFO ของสื่อไม่เปลี่ยนแปลง

ไฟล์ NFO ที่แยกวิเคราะห์ไม่ได้จะถูกบันทึกเป็นข้อผิดพลาด แทนการซ่อมโดยอัตโนมัติ

---

### การบำรุงรักษา Web Card ที่กู้คืนได้

การติดตั้ง อัปเดต หรือลบไฟล์เว็บ Emby แยกจากข้อมูล NFO ของสื่อโดยสิ้นเชิง

งานบำรุงรักษาเหล่านี้ออกแบบให้:

* ยืนยันเป้าหมายที่แน่นอน
* สร้างข้อมูลสำรอง
* ตรวจสอบว่ากู้คืนข้อมูลสำรองได้
* สร้างผลลัพธ์ที่แก้ไขฉบับสมบูรณ์
* รักษาพฤติกรรม BOM / การขึ้นบรรทัดใหม่ที่จำเป็น
* ตรวจสอบผลลัพธ์หลังเสร็จสิ้น
* ย้อนกลับเมื่อเกิดข้อผิดพลาด

งานที่ต้องใช้สิทธิ์ผู้ดูแลระบบจะดำเนินการอย่างชัดเจนผ่าน Windows UAC

---

### การย้ายคอมโพเนนต์เก่าอย่างระมัดระวัง

TCM ยังคงตรวจจับความเข้ากันได้ของคอมโพเนนต์เก่าบางรายการ Web Patch รุ่นเก่า และร่องรอยการติดตั้งในอดีต

สำหรับงานที่มีผลข้างเคียง เช่น:

* ลบคอมโพเนนต์เก่า
* ยุติโพรเซส
* แทนที่ Web Patch
* ล้างไฟล์ในอดีต

กระบวนการที่กำหนดไว้คือ:

```text
ระบุเป้าหมาย
    ↓
แสดงแผนบำรุงรักษา
    ↓
การยืนยันจากผู้ใช้
    ↓
ตรวจสอบเป้าหมายซ้ำ
    ↓
ดำเนินการ
    ↓
ตรวจสอบผลลัพธ์
```

หาก TCM ไม่สามารถระบุความเป็นเจ้าของคอมโพเนนต์เก่าได้อย่างเชื่อถือได้ ระบบจะหยุดแทนการเสี่ยงลบอย่างไม่ปลอดภัย

จากนั้นเรียกใช้:

```text
Tech-Card-Manager.exe
```

อย่าเรียกใช้แอปโดยตรงจากภายในไฟล์บีบอัด

### 3. กำหนดค่าคลังสื่อ

หลังเริ่มครั้งแรก ให้กำหนดค่ารากคลังที่เกี่ยวข้องในตัวจัดการ

สามารถกำหนดรากภาพยนตร์และรายการทีวีแยกกันได้

ตัวอย่าง:

```text
ภาพยนตร์
  └── D:\Movies

รายการทีวี
  └── D:\TV
```

TCM อ่านไฟล์ NFO ที่เกี่ยวข้องจากไดเรกทอรีเหล่านี้
TCM ยังสามารถค้นพบไดเรกทอรีคลังจาก Emby Server โดยอัตโนมัติ

---

### 4. สร้างดัชนี

รีเฟรชคลังที่สอดคล้องกับพื้นที่ภาพยนตร์หรือรายการทีวีปัจจุบัน

```text
NFO
 ↓
แยกวิเคราะห์
 ↓
ดัชนีอนุพันธ์
```

กระบวนการนี้ไม่เขียนข้อมูลดัชนีกลับไปยังไฟล์ NFO

---

### 5. กำหนดค่า Emby Web Card

ทำตามสถานะและคำแนะนำในตัวจัดการเพื่อติดตั้งหรือบำรุงรักษา Emby Web Card

Windows อาจขอสิทธิ์ผู้ดูแลระบบเมื่อต้องแก้ไขไฟล์เว็บ Emby

---

### 6. ให้ TCM ทำงานต่อ

TCM ให้บริการภายในเครื่องที่ Web Card ใช้เข้าถึงดัชนีและแอสเซ็ตที่เกี่ยวข้อง

ดังนั้น TCM ต้องทำงานอยู่ระหว่างการใช้การ์ด Technical Specifications

ตัวจัดการสามารถย่อไปยังถาดระบบและไม่ต้องแสดงอยู่บนเดสก์ท็อป

## ⚠️ ข้อสงวนสิทธิ์

Tech Card Manager เป็นโครงการโอเพนซอร์สที่พัฒนาขึ้นโดยอิสระ

โครงการนี้ **ไม่มีความเกี่ยวข้องอย่างเป็นทางการ ไม่ได้รับอนุญาต หรือรับรองโดย Emby, IMDb หรือแพลตฟอร์มบุคคลที่สามอื่นใด**

ชื่อ เครื่องหมายการค้า ข้อมูล และบริการของบุคคลที่สามทั้งหมดยังคงเป็นทรัพย์สินของเจ้าของแต่ละราย

TCM ไม่รับผิดชอบแหล่งที่มาหรือสถานะสิทธิ์ใช้งานของข้อมูล Technical Specifications จากบุคคลที่สาม

ผู้ใช้มีหน้าที่ตรวจสอบว่าเมทาดาทาสื่อ ข้อมูลบุคคลที่สาม และการใช้บริการที่เกี่ยวข้องเป็นไปตามข้อกำหนดการให้บริการ ข้อกำหนดสิทธิ์ใช้งาน และกฎหมายที่เกี่ยวข้อง

## 💡 ความคิดเห็นและข้อเสนอแนะ

Tech Card Manager จะพัฒนาต่อไปในด้านต่อไปนี้:

* การจัดทำดัชนี Technical Specifications แบบอ่านอย่างเดียว
* Emby Technical Specifications Card
* การนำเสนอในคลังสื่อ
* การผสานรวม Web UI
* ประสบการณ์ผู้ใช้ Windows
* ความเข้ากันได้กับ Emby
* ความเสถียร
* กระบวนการพัฒนาด้วย Coding Agents

หากมีแนวคิดเกี่ยวกับเลย์เอาต์การ์ด ความเข้ากันได้ของประเภทสื่อ การผสานรวมหน้า Emby การเรียกดูดัชนี การใช้งาน Windows หรือกระบวนการพัฒนา ยินดีให้เข้าร่วมผ่าน Issues
