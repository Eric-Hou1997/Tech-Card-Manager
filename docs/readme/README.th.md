## เกี่ยวกับโครงการ

Tech Card Manager (TCM) สแกน NFO ของภาพยนตร์และรายการทีวีที่ผู้ใช้เลือกในโหมดอ่านอย่างเดียว สร้างดัชนีของตัวเอง และแสดงข้อมูลกล้อง เลนส์ รูปแบบการถ่ายทำ เสียง อัตราส่วนภาพ และกระบวนการผลิตผ่าน Emby Web Card

TCM ไม่ดึงข้อมูล IMDb ไม่เขียน NFO และไม่สร้างแท็ก หากต้องการสร้างหรือดูแลข้อมูลเหล่านี้ ให้ใช้แอปแยก [IMDb Tech Manager (ITM)](https://github.com/Eric-Hou1997/IMDb-Tech-Manager)

## เวอร์ชันและแพลตฟอร์ม

- เวอร์ชันเสถียร: [`v4.1.0`](https://github.com/Eric-Hou1997/Tech-Card-Manager/releases/tag/v4.1.0)
- แพลตฟอร์ม: Windows x64 Portable
- ไฟล์เผยแพร่: `TCM-v4.1.0-Windows-x64-EXE.zip`
- ชื่อไฟล์ภายใน ZIP คงที่เป็น `Tech-Card-Manager.exe`
- Release มี SHA-256 คำแนะนำ บันทึกการเปลี่ยนแปลง และแพ็กภาษา

## ความสามารถหลัก

- โฟลเดอร์ ดัชนี การค้นหา ตัวกรอง และขอบเขตการรีเฟรชแยกสำหรับภาพยนตร์และรายการทีวี
- NFO Inspector แบบอ่านอย่างเดียวและการวินิจฉัย XML พร้อมเส้นทางเต็ม
- ติดตั้ง อัปเดต ลบ และตรวจสอบสถานะ Emby Web Card
- Windows แบบอินสแตนซ์เดียว ถาดระบบ เริ่มหลังล็อกอิน และโหมดเงียบ
- เลย์เอาต์หัวเรื่อง แดชบอร์ด เครื่องมือ NFO และสองพาเนลที่ปรับตามความกว้างเนื้อหา
- ตรวจอัปเดตโดยแยกข้อผิดพลาดพร็อกซี/เครือข่าย ขีดจำกัด GitHub ไฟล์หาย และดาวน์โหลดล้มเหลว

## ภาษา

ภาษาจีนตัวย่อ ภาษาจีนตัวเต็ม และ English (United States) รวมอยู่ใน EXE แบบ Portable ส่วนภาษาฝรั่งเศส รัสเซีย ญี่ปุ่น สเปน และไทยเผยแพร่เป็นแพ็กแยกใน Release `v4.1.0` และจะโหลดหลังจากดาวน์โหลดและตรวจสอบแล้วเท่านั้น

ภาษาของบันทึกใหม่จะถูกกำหนดเมื่อเริ่มงาน บันทึกเดิม NFO ดัชนี ข้อมูลสำรอง และข้อมูลผู้ใช้จะไม่ถูกเขียนทับ ภาษา Emby ที่ไม่ได้ติดตั้งหรือไม่รองรับจะย้อนกลับเป็นภาษาจีนตัวย่อ คีย์ `Camera`, `Sound mix` และโครงสร้าง JSON คงเดิม โดยแปลเฉพาะข้อความที่แสดง

## ขอบเขตความปลอดภัย

- NFO เป็นแหล่งข้อมูลแบบอ่านอย่างเดียวสำหรับ TCM เสมอ การสร้างดัชนีไม่เปลี่ยนไบต์หรือเวลาของไฟล์
- การดูแล Web Card ทำเฉพาะไฟล์ Web ของ Emby ที่ตรวจสอบแล้ว พร้อมข้อมูลสำรองภายนอก การล็อก CAS บันทึก และการแทนที่แบบอะตอม
- การย้ายส่วนประกอบเก่าหรือการทำงานของผู้ดูแลระบบจะแสดงแผนและต้องยืนยันอย่างชัดเจน
- หากตรวจสอบเส้นทาง ความเป็นเจ้าของ หรือข้อมูลสำรองไม่ได้ ระบบจะหยุดอย่างปลอดภัย

## การติดตั้งและอัปเดต

แตก ZIP ให้ครบ เปิด `Tech-Card-Manager.exe` ตั้งค่าโฟลเดอร์ภาพยนตร์และรายการทีวีแยกกัน สร้างดัชนี แล้วทำตามหน้าจอเพื่อตั้งค่า Web Card ต้องเปิด TCM ระหว่างใช้งานการ์ด และสามารถย่อไปยังถาดระบบได้

เวอร์ชัน Portable จะไม่แทนที่ EXE ที่กำลังทำงานโดยอัตโนมัติ ให้ออกจากถาดระบบทั้งหมด แตกเวอร์ชันใหม่ และแทนที่โปรแกรมโดยเก็บ `data`, `logs`, `backup`, `runtime` และ `updates`

## Roadmap

เสร็จแล้ว: Windows x64 Portable, ดัชนี NFO แบบอ่านอย่างเดียว, พื้นที่ภาพยนตร์/ทีวีแยกกัน, Web Card ที่ปลอดภัย, วงจรถาดระบบ, รีจิสทรีหลายภาษาและแพ็กห้าภาษา, การอัปเดตที่รองรับพร็อกซี และเลย์เอาต์ที่วัดจากเนื้อหา

กำลังดำเนินการ: การทดสอบจริงบน Windows/Emby/PowerShell 5.1/UAC, ความเข้ากันได้กับ Emby DOM และชนิดสื่อ, การกู้คืนส่วนประกอบเก่า, การอัปเดต Portable และแพลตฟอร์มอื่น
