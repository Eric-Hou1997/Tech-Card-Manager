# 维护者模拟 NFO 库验收

状态：本批样本通过已列出的本机检查；不是第 5–8 步整体完成声明。样本由维护者提供，来自 `模拟nfo/电影` 和 `模拟nfo/电视剧`，没有复制到 Git 仓库。

## 样本与结果

- 101 个 NFO：27 个 movie、1 个 tvshow、73 个 episodedetails，共 2,359,353 字节。
- Rust 核心使用临时数据库分别执行 Movie 和 TV 的首次扫描、未改动刷新；均 completed，错误为 0。两轮索引内容一致。
- 所有条目均逐项执行 Inspector 查询和文件名搜索；关闭并重开数据库后保留 4 条扫描历史。
- 原生界面通过系统目录选择框加入两个根目录，新目录默认不勾选。Movie 扫描完成 27 项，TV 完成 74 项；中文搜索“权力”返回《权力的游戏》Series，Inspector 展示 2011、tt0944947、tvshow.nfo 路径、Specs 与标签归属。
- GUI 使用现有隔离验证安装，其实际二进制哈希单独记录；当前 Rust 核心由命令行验收入口独立运行。Movie 总目录还有此前 3 份隔离用例，因此界面总计 30 项；本次任务的 27 项范围正确。
- 两个验证应用均已退出，未留下应用进程。测试前后全部 102 个普通文件（包括 101 个 NFO）的 SHA-256、纳秒 mtime、权限、大小和文件清单完全一致。

证据：[样本验收 JSON](evidence/simulated-nfo-acceptance.json)。记录了源码、GUI 二进制和前后样本清单的哈希，未把 NFO 原始内容放入报告。

## 复现读取检查

在 `rewrite/src-tauri` 中执行，替换两个路径为维护者提供的样本目录：

```sh
cargo run --locked -p tcm-core --example library_acceptance -- '/path/to/模拟nfo/电影' '/path/to/模拟nfo/电视剧' > /tmp/tcm-sample-read.json
```

入口使用临时 SQLite，只读取给定媒体根目录；当前验收入口限制每空间最多 500 项，不能将本次耗时外推为大库性能承诺。对源文件属性的前后快照应由调用方同时记录。

## 本轮发现的验证壳问题

`REWRITE-UI-CMD-Q` 已修复并完成本机原生回归。原实现把普通菜单项直接放到 macOS 菜单栏顶层，导致 ⌘Q 不生效；现改为应用子菜单，并给托盘独立菜单项。两产品均从新 DMG 隔离安装，禁用自动退出，在搜索框聚焦时实际按 ⌘Q；退出码为 0，完成同步工作线程清理，无残留进程，临时安装已删除。旧样本记录里的失败事实保留，当前修复证据见 [退出快捷键回归](evidence/quit-shortcut-fix.json)。

复现：运行 `python3 tools/rewrite/macos_smoke.py --manual-quit`，打开输出中的临时应用路径，聚焦搜索框并按 ⌘Q。脚本必须观察到 IPC 和最终退出事件并检查无残留进程；不能通过点击退出按钮替代这项按键回归。Windows/Linux 快捷键尚未实机验证。
