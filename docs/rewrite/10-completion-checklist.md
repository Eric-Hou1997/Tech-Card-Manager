### 常驻索引发布与续租分离（2026-09-11）

- 卡片心跳与索引发布采用两个明确所有者，磁盘校验与全库构造不持有 UI 状态锁。停止时等待发布结束，再停止并等待续租，最后明确禁用运行租约。失败仍保留结构化原因。

- 新 Store 联动服务在 Linux 双架构、macOS 和 Windows x64 的真实 Emby 回归通过；Windows ARM 在八语言展示之后，停止时遇到 Emby 文件替换 Access denied（34581478644），本轮不得按五目标通过放行。
