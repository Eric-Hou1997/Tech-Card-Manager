# TCM Manager 展示语言迁移

状态：原版语言选择器及 ZIP 语言包链路已接入重写代码，尚未通过真实原生窗口、下载及八语言全流程验收。当前要求以 `15-baseline-only-correction.md` 为准。

## 当前实现

`rewrite/src/LanguagePicker.vue` 保留 4.1.0 的八行、矩形旗帜、当前语言/本地名布局、下载/加载/失败图标和兼容 select。`baseline-language.ts` 使用原版翻译与相同文本边界，排除路径、规格值、标签、用户标题和旧日志；Vue 仍负责应用状态和业务调用。原文资源从基线提取，没有重译原版文案。

`rewrite/src-tauri/core/src/languages.rs` 读取原 `windows/language_catalog.json`，只接受其绑定的五个 `TCM-Language-<locale>-r<revision>.zip`。版本、原始 ZIP 摘要、固定六文件集合、清单身份、每个分区摘要和解压大小都必须通过；只读取字典，不执行包中内容。SQLite 保留经验证 ZIP 字节，重启重新校验，错误重装不能覆盖有效缓存。

已导入 SQLite 的旧解压包也可复用：只接受同一次导入、同一个语言/修订目录中的六个文件，先核对导入摘要，再验证原版清单和分区摘要。原目录移走、重启后仍可读取；不完整的新导入不会借用旧导入文件，双目录歧义和损坏明确失败。它遵循旧版已安装文件的验证约定，不构造新 ZIP，也不宣称取得原始 ZIP 摘要验证证据。

原生命令负责状态、限定地址下载、语言保存和菜单文本同步。语言保存独立于媒体目录检查，只改变配置语言/修订号，不改媒体、已有索引或此前任务的语言快照；失败后前端读取实际保存状态。下载状态和前端观察器/监听器均有释放逻辑。

启动恢复沿用原版候选规则：只处理当前选择或曾安装的外部语言，有效包跳过；旧修订目录及新安装的事务记录用于判断安装历史。同一包不会并发下载，失败在本次进程内不反复自动重试，用户仍可主动重试。恢复不改变选中语言，期间可切换内置语言；前端读取当前状态，不用恢复结束时的旧结果覆盖用户新选择。

先前 schema 2 JSON 格式与专属模块/测试已经删除；它们没有 4.1.0 对应格式，也没有正式已发布资产。该清理只针对 TCM 重写中的冗余实现，不改旧版 ZIP、翻译、发布目录、用户缓存或 ITM。
