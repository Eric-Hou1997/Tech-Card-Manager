# 第 5–8 步迁移执行记录（历史）

状态：本文件保留旧阶段证据，不再作为当前执行清单；其中“部分实现”“必须继续完成”等状态已被 `16-replan-2026-09-13.md` 和 `15-baseline-only-correction.md` 的当前源码台账取代。开发位于 `v5.0.0-rewrite`；旧平台代码和正式业务引擎仍保留。

## 已实现的基础和读取链

- `rewrite/src-tauri/core/` 为独立可测试 Rust 核心。Vue → Tauri 命令/事件 → Store/读取用例 → XML/路径/SQLite 适配；两仓库独立构建，不运行时互相引用。
- Rust 生成 TypeScript 类型；配置 revision CAS、数据库版本拒绝降级、单一数据库所有者、持久化操作结果与跨操作种类 ID 冲突检查。
- 扫描任务明确根目录范围和 Movie/TV 空间，冻结启动语言；内部持久化进度、历史、中断和取消用于恢复与清理，不向 TCM 用户增加暂停/恢复任务入口。重试从根重新遍历并复用未改变的索引，不是旧引擎游标直接续跑。
- 只读 NFO 解析、根标签权威归属、Technical Specs、同 IMDb 不同路径条目的独立身份。保存 source hash/parser revision，增量刷新；异常路径可定位，离线根保留已有索引。
- Vue 工作台保留原版根目录选择、当前媒体库刷新、搜索、状态筛选、当前 NFO 预览、文件管理器定位和单一任务日志。Movie/TV 的窗口内搜索和选择各自保留；没有分页、Inspector 编辑器或通用任务控制面板。
- 凭据只有 Rust 接口，原生 keyring 适配；前端没有获取凭据的通用命令。已定义 8 语言注册表、任务语言快照，完整界面翻译和语言包流程尚未接入。
- 本地窗口权限与 CSP 保持隔离，外部网页没有管理命令；工作线程/事件监听/计时器分别持有并清理。退出时等待扫描线程停止。

## 显式差异与限制

- TCM 像 v4.1.0 一样只读完整 NFO，不另加重写版文件大小上限；DTD、符号链接/Windows reparse 路径仍失败并定位，不擅自修复或绕过。
- ITM 归属比较使用 Python 对应的 Unicode full casefold；TCM 保留其原版小写比较语义。ITM 合并已知 Specs 重复 section，TCM 保留最后 section；未将两个产品不同旧行为强行统一。
- 扫描取消在读取检查点生效；网络文件系统阻塞读、权限与锁行为必须真实平台验证。当前单元测试不证明任意网络故障都能即时退出。
- TCM 的 Emby 权限、手动更新、人工升级/卸载验收阻塞继续有效；IMDb HTTP 与 OTA 签名只属于 ITM，不作为本产品完成条件。
- 未迁移功能均仍在 [完整功能台账](features.json)；`partial` 只代表列出的实现片段，不表示整个功能组或原版入口验收通过。

## TCM 产品边界

TCM 核心不包含 ITM 的 AI、规则生成、Specs 写入或事务模块。当前源码已接通原版只读目录、Emby 资源发布、Web Card、旧组件维护、手动更新、修复/禁用/移除和回滚；真实 Emby 客户端、原生授权与五目标平台验收仍未完成。只读测试不会替代这些外部链路证据。
