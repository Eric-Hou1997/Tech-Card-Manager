# プライバシーポリシー

[简体中文](../../PRIVACY.md) | [繁體中文](./PRIVACY.zh-Hant.md) | [English](./PRIVACY.en.md) | [Français](./PRIVACY.fr.md) | [Русский](./PRIVACY.ru.md) | **日本語** | [Español](./PRIVACY.es.md) | [ไทย](./PRIVACY.th.md)

Tech Card Manager はローカルで動作する Windows ポータブルアプリです。本製品独自のテレメトリー、広告追跡、アカウントシステムは運用しません。

- 選択したメディアフォルダー、読み取り専用 NFO インデックス、設定、ログ、バックアップ、実行時ファイルはポータブルアプリのフォルダーに保存されます。
- GitHub への接続は **更新を確認** を選択した場合に限られ、Releases ページは **GitHub へ進む** を選択した後にのみ開きます。
- ローカル NFO と設定済み Emby Server ファイルは、利用者が開始した操作のためだけに読み取られます。メディア NFO は常に読み取り専用です。

本ポリシーは正式リリースに合わせて更新されます。ソース内の仮の公開日は該当リリース時に確定します。
