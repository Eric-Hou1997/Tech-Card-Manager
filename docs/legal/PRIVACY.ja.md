# プライバシーポリシー

[简体中文](../../PRIVACY.md) | [繁體中文](./PRIVACY.zh-Hant.md) | [English](./PRIVACY.en.md) | [Français](./PRIVACY.fr.md) | [Русский](./PRIVACY.ru.md) | **日本語** | [Español](./PRIVACY.es.md) | [ไทย](./PRIVACY.th.md)

Tech Card Manager は macOS、Windows、Linux のローカルデスクトップツールで、独自のテレメトリー、広告追跡、アカウントシステムはありません。

- 設定、読み取り専用 NFO からの派生インデックス、ログ、実行状態はシステムのユーザーデータ領域に保存し、アプリ識別子は `io.github.eric-hou1997.tcm` です。旧 Portable ファイルは移行元として保持し、Emby 保守バックアップは権限保護された保守領域に保存します。
- 設定を開くか更新確認を要求すると、元のキャッシュ規則に従い GitHub の公式リリース情報へ接続することがあります。言語パックのインストール/復元でも対応する公式 Release から取得・検証します。ダウンロードを承認した場合のみシステムブラウザーを開き、更新を自動インストールしません。
- 設定と要求された操作に従いメディア NFO と Emby Server ファイルを読みます。メディア NFO は常に読み取り専用です。Emby ウェブファイルの保守には確認が必要で、バックアップと復旧経路を提供します。

本方針は v5.0.0 に適用します。更新日：2026-10-02。
