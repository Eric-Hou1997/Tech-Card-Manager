# นโยบายความเป็นส่วนตัว

[简体中文](../../PRIVACY.md) | [繁體中文](./PRIVACY.zh-Hant.md) | [English](./PRIVACY.en.md) | [Français](./PRIVACY.fr.md) | [Русский](./PRIVACY.ru.md) | [日本語](./PRIVACY.ja.md) | [Español](./PRIVACY.es.md) | **ไทย**

Tech Card Manager เป็นแอป Windows แบบพกพาที่ทำงานภายในเครื่อง โดยไม่มีระบบโทรมาตร การติดตามโฆษณา หรือบัญชีผู้ใช้ของผลิตภัณฑ์เอง

- โฟลเดอร์สื่อ ดัชนี NFO แบบอ่านอย่างเดียว การตั้งค่า บันทึก สำเนาสำรอง และไฟล์รันไทม์จะเก็บในโฟลเดอร์แอปแบบพกพา
- แอปจะสอบถาม GitHub เฉพาะเมื่อเลือก **ตรวจสอบการอัปเดต** และจะเปิดหน้า Releases หลังจากเลือก **ไปยัง GitHub** เท่านั้น
- แอปอ่าน NFO ภายในเครื่องและไฟล์ Emby Server ที่ตั้งค่าไว้เฉพาะสำหรับงานที่คุณเริ่มต้น ไฟล์ NFO ของสื่อจะเป็นแบบอ่านอย่างเดียวเสมอ

นโยบายนี้ปรับปรุงพร้อมรุ่นทางการ วันที่ชั่วคราวในซอร์สโค้ดจะถูกแทนที่สำหรับรุ่นที่เกี่ยวข้อง
