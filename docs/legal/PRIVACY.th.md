# นโยบายความเป็นส่วนตัว

[简体中文](../../PRIVACY.md) | [繁體中文](./PRIVACY.zh-Hant.md) | [English](./PRIVACY.en.md) | [Français](./PRIVACY.fr.md) | [Русский](./PRIVACY.ru.md) | [日本語](./PRIVACY.ja.md) | [Español](./PRIVACY.es.md) | **ไทย**

Tech Card Manager เป็นเครื่องมือเดสก์ท็อปภายในเครื่องสำหรับ macOS, Windows และ Linux ไม่มีระบบโทรมาตร การติดตามโฆษณา หรือบัญชีของตนเอง

- การตั้งค่า ดัชนีที่สร้างจาก NFO แบบอ่านอย่างเดียว บันทึก และสถานะทำงานอยู่ในไดเรกทอรีข้อมูลผู้ใช้ของระบบ โดยใช้ตัวระบุ `io.github.eric-hou1997.tcm` ไฟล์ Portable เก่ายังเป็นแหล่งย้ายข้อมูล สำรอง Emby อยู่ในไดเรกทอรีบำรุงรักษาที่ป้องกันด้วยสิทธิ์
- การเปิดตั้งค่าหรือขอตรวจอัปเดตอาจเชื่อมต่อ GitHub เพื่อสอบถามรุ่นเผยแพร่ทางการ โดยคงกฎแคชเดิม การติดตั้ง/กู้คืนชุดภาษาดาวน์โหลดและตรวจจาก Release ทางการที่ผูกไว้เช่นกัน เปิดเบราว์เซอร์ระบบหลังยืนยันดาวน์โหลดเท่านั้น แอปไม่ติดตั้งอัปเดตอัตโนมัติ
- แอปอ่าน NFO และไฟล์ Emby Server ตามการตั้งค่าและการดำเนินการที่ร้องขอ NFO ของสื่อเป็นแบบอ่านอย่างเดียวเสมอ การบำรุงรักษาไฟล์เว็บ Emby ต้องยืนยัน และมีทางสำรองกับกู้คืน

นโยบายใช้กับ v5.0.0 อัปเดต: 2026-10-02
