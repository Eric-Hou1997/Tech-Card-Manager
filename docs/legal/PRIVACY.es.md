# Política de privacidad

[简体中文](../../PRIVACY.md) | [繁體中文](./PRIVACY.zh-Hant.md) | [English](./PRIVACY.en.md) | [Français](./PRIVACY.fr.md) | [Русский](./PRIVACY.ru.md) | [日本語](./PRIVACY.ja.md) | **Español** | [ไทย](./PRIVACY.th.md)

Tech Card Manager es una aplicación portátil y local para Windows. No mantiene telemetría, seguimiento publicitario ni un sistema de cuentas propios.

- Las carpetas multimedia, el índice NFO de solo lectura, los ajustes, registros, copias de seguridad y archivos de ejecución se almacenan en la carpeta de la aplicación portátil.
- Solo consulta GitHub al seleccionar **Buscar actualizaciones** y únicamente abre Releases después de seleccionar **Continuar a GitHub**.
- Lee los NFO locales y los archivos configurados de Emby Server solo para operaciones iniciadas por ti. Los NFO multimedia permanecen siempre en modo de solo lectura.

Esta política se actualiza con las versiones oficiales. Cualquier fecha provisional del código fuente se sustituirá para la versión correspondiente.
