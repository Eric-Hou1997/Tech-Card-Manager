# Política de privacidad

[简体中文](../../PRIVACY.md) | [繁體中文](./PRIVACY.zh-Hant.md) | [English](./PRIVACY.en.md) | [Français](./PRIVACY.fr.md) | [Русский](./PRIVACY.ru.md) | [日本語](./PRIVACY.ja.md) | **Español** | [ไทย](./PRIVACY.th.md)

Tech Card Manager es una herramienta local de escritorio para macOS, Windows y Linux. No tiene sistemas propios de telemetría, seguimiento publicitario ni cuentas.

- Ajustes, índice derivado NFO de solo lectura, registros y estado de ejecución se guardan en el directorio de usuario del sistema con la identidad `io.github.eric-hou1997.tcm`. Los archivos Portable antiguos se conservan como origen de migración; las copias Emby están en un directorio de mantenimiento protegido por permisos.
- Abrir Ajustes o solicitar una comprobación puede conectar a GitHub para consultar publicaciones oficiales, manteniendo las reglas originales de caché. La instalación/restauración de paquetes de idioma también descarga y verifica recursos de la Release oficial vinculada. El navegador del sistema se abre solo tras confirmar la descarga; la aplicación no instala actualizaciones automáticamente.
- La aplicación lee NFO y archivos Emby Server según la configuración y las operaciones solicitadas. Los NFO de medios siempre son de solo lectura. El mantenimiento web Emby exige confirmación y ofrece copias y recuperación.

Esta política se aplica a v5.0.0. Actualizada: 2026-10-02.
