# Политика конфиденциальности

[简体中文](../../PRIVACY.md) | [繁體中文](./PRIVACY.zh-Hant.md) | [English](./PRIVACY.en.md) | [Français](./PRIVACY.fr.md) | **Русский** | [日本語](./PRIVACY.ja.md) | [Español](./PRIVACY.es.md) | [ไทย](./PRIVACY.th.md)

Tech Card Manager — локальное переносимое приложение Windows. Оно не использует собственную телеметрию, рекламное отслеживание или систему учётных записей.

- Выбранные медиапапки, индекс NFO только для чтения, настройки, журналы, резервные копии и рабочие файлы хранятся в папке переносимого приложения.
- Приложение обращается к GitHub за сведениями об официальных выпусках только после выбора **Проверить обновления**. Страница Releases открывается лишь после выбора **Перейти на GitHub**.
- Локальные NFO и настроенные файлы Emby Server читаются только для запущенных вами операций. Медиаданные NFO всегда остаются доступными только для чтения.

Политика обновляется вместе с официальными выпусками. Предварительная дата в исходном коде будет заменена для соответствующего выпуска.
