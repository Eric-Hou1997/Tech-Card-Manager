# Политика конфиденциальности

[简体中文](../../PRIVACY.md) | [繁體中文](./PRIVACY.zh-Hant.md) | [English](./PRIVACY.en.md) | [Français](./PRIVACY.fr.md) | **Русский** | [日本語](./PRIVACY.ja.md) | [Español](./PRIVACY.es.md) | [ไทย](./PRIVACY.th.md)

Tech Card Manager — локальный инструмент для macOS, Windows и Linux, без собственной телеметрии, рекламного отслеживания или системы аккаунтов.

- Настройки, производный индекс NFO только для чтения, журналы и состояние выполнения сохраняются в пользовательском каталоге системы с идентификатором `io.github.eric-hou1997.tcm`. Старые файлы Portable остаются источниками миграции; резервные копии Emby хранятся в защищённом правами каталоге обслуживания.
- Открытие настроек или запрос проверки обновления может обращаться к GitHub за официальными релизами с сохранением исходных правил кеширования. Установка/восстановление языковых пакетов также загружает и проверяет ресурсы привязанного официального Release. Системный браузер открывается только после подтверждения загрузки; приложение не устанавливает обновления автоматически.
- Приложение читает NFO и файлы Emby Server по настройкам и запрошенным операциям. NFO медиафайлов всегда доступны только для чтения. Обслуживание веб-файлов Emby требует подтверждения и предусматривает резервирование и восстановление.

Политика относится к v5.0.0. Обновлена: 2026-10-02.
